# DeskPet 桌面宠物 · 用户使用指南

> 一个会主动找你聊天的桌面宠物。它抓取全网热点、理解你的兴趣画像，用自然的口吻主动告诉你值得关注的内容。

---

## 一、安装

### 1.1 安装包

双击 `DeskPet_0.1.0_x64-setup.exe`（NSIS）或 `DeskPet_0.1.0_x64_en-US.msi`（MSI），按提示完成安装。

### 1.2 运行

安装完成后，从开始菜单或桌面快捷方式启动 **DeskPet**。

启动后你会看到：
- 桌面上出现一只橙色小猫（宠物窗口，始终置顶、无边框、透明）
- 系统托盘出现小猫图标

> 💡 首次运行时，程序会自动在数据目录生成配置文件和数据库。

---

## 二、配置 LLM（必须完成才能正常使用）

DeskPet 需要一个 OpenAI 兼容的 LLM API Key 来生成口播文案和做语义去重。不配置也能运行，但功能会降级（口播变为模板文案、无智能匹配）。

### 2.1 配置文件路径

配置文件位于：

```
C:\Users\admin\AppData\Roaming\deskpet\config.toml
```

> 把 `admin` 替换成你自己的 Windows 用户名。如果不确定用户名，按 `Win + R`，输入 `%APPDATA%\deskpet` 回车，即可直接打开该目录。

首次运行后该文件会自动生成。用记事本或任意文本编辑器打开它。

### 2.2 填入 API Key

找到 `[llm]` 段落，填入你的 API Key：

```toml
[llm]
# OpenAI 兼容端点，必须带 /v1
#   OpenAI:   https://api.openai.com/v1          模型 gpt-4o-mini
#   DeepSeek: https://api.deepseek.com/v1        模型 deepseek-chat（无 embeddings，embedding_model 留空）
#   通义千问: https://dashscope.aliyuncs.com/compatible-mode/v1  模型 qwen-plus
#   Kimi:     https://api.moonshot.cn/v1         模型 moonshot-v1-8k
api_base = "https://api.openai.com/v1"
api_key = "YOUR_API_KEY"   # ← 在这里填你的 API Key
model = "gpt-4o-mini"
# 向量模型；如果你的服务不提供 embeddings 接口（如 DeepSeek），设为 "" 即可关闭
embedding_model = "text-embedding-3-small"
```

保存文件即可，**无需重启**——程序每 5 秒自动检测配置变化并热重载。

### 2.3 各服务商配置示例

#### OpenAI

```toml
[llm]
api_base = "https://api.openai.com/v1"
api_key = "sk-your-openai-key"
model = "gpt-4o-mini"
embedding_model = "text-embedding-3-small"
```

#### DeepSeek

```toml
[llm]
api_base = "https://api.deepseek.com/v1"
api_key = "sk-your-deepseek-key"
model = "deepseek-chat"
embedding_model = ""   # DeepSeek 无 embeddings 接口，留空关闭
```

#### 通义千问（阿里 DashScope）

```toml
[llm]
api_base = "https://dashscope.aliyuncs.com/compatible-mode/v1"
api_key = "sk-your-dashscope-key"
model = "qwen-plus"
embedding_model = "text-embedding-v3"
```

#### Kimi（Moonshot）

```toml
[llm]
api_base = "https://api.moonshot.cn/v1"
api_key = "sk-your-kimi-key"
model = "moonshot-v1-8k"
embedding_model = ""   # Kimi 无 embeddings 接口，留空关闭
```

### 2.4 环境变量方式（备选）

也可以通过环境变量 `DESKPET_LLM_KEY` 设置 API Key（仅在配置文件首次生成且不含 `api_key` 字段时生效，一旦文件中已有该字段则以文件为准）：

```powershell
$env:DESKPET_LLM_KEY = "sk-your-api-key-here"
```

## 三、使用操作

### 3.1 与宠物交互

| 操作 | 效果 |
|---|---|
| **拖拽** | 按住宠物拖动到桌面任意位置 |
| **双击** | 立即触发一次热点播报（跳过勿扰/间隔限制） |
| **滚轮** | 手动切换宠物情绪（idle → happy → curious → excited → sleepy → bored） |

### 3.2 气泡窗口

宠物会在合适的时机主动弹出气泡播报热点。气泡窗口位于宠物上方（顶部空间不足时自动放到下方）。

气泡内容：
- **标题**：热点标题
- **文案**：LLM 生成的口语化口播
- **查看原文 →**：用系统默认浏览器打开该热点链接
- **喜欢**：标记感兴趣，宠物会学到你的偏好
- **不感兴趣**：标记不喜欢，减少同类内容推送
- **关闭**：隐藏气泡（不记录反馈）

> 气泡 15 秒后自动隐藏。

### 3.3 系统托盘

右键点击系统托盘中的小猫图标，可：
- **显示宠物** / **隐藏宠物**
- **立即播报**：强制触发一次热点采集和播报
- **退出**：关闭程序

左键单击托盘图标可快速显示/隐藏宠物。

### 3.4 情绪状态

宠物有 6 种情绪，动画会随情绪变化：

| 情绪 | 说明 | 触发场景 |
|---|---|---|
| idle | 待机呼吸 | 平时 |
| happy | 开心蹦跳 | 你点了"喜欢" |
| curious | 歪头好奇 | 双击召唤、暂无热点 |
| excited | 兴奋跳跃 | 发现非常感兴趣的热点 |
| sleepy | 犯困闭眼 | 暂无对应触发 |
| bored | 蔫蔫下垂 | 你点了"不感兴趣" |

## 四、其他配置项

除了 LLM，`config.toml` 中还有以下常用配置：

```toml
[general]
quiet_hours = ["23:00-08:00"]        # 勿扰时段，此时段不主动播报
min_announce_interval_min = 45        # 两次播报最小间隔（分钟）
announce_threshold = 0.6              # 打分阈值，低于此值的热点不播报

[fetch]
rsshub_endpoint = "https://rsshub.app"   # RSSHub 兜底地址
default_interval_min = 15                # 默认采集间隔

[[fetch.platforms]]
id = "zhihu"
enabled = true
interval_min = 10

[[fetch.platforms]]
id = "bilibili"
enabled = true
interval_min = 15

[[fetch.platforms]]
id = "weibo"
enabled = true
interval_min = 20

[[fetch.platforms]]
id = "rsshub"
enabled = true
interval_min = 30

[[fetch.platforms]]
id = "douyin"
enabled = true
interval_min = 30

[[fetch.platforms]]
id = "xiaohongshu"
enabled = true
interval_min = 30

[tts]
provider = "edge"
voice = "zh-CN-XiaoxiaoNeural"   # 语音角色
enabled = true                    # 是否启用语音播报
```

### 热重载

以下字段修改后自动生效（5 秒内），无需重启：
- `general.quiet_hours`
- `general.min_announce_interval_min`
- `fetch.platforms[].interval_min`
- `llm.api_base` / `llm.api_key` / `llm.model` / `llm.embedding_model`（LLM 配置变化时会自动重建客户端）

以下字段需**重启**生效：
- `fetch.platforms[].enabled`（平台启用/禁用）
- `fetch.rsshub_endpoint`
- `tts.*`（TTS 实例在启动时构建）

## 五、数据目录

所有运行时数据保存在：

```
C:\Users\admin\AppData\Roaming\deskpet\
├── config.toml       # 配置文件
├── deskpet.db        # SQLite 数据库（热点/画像/反馈）
├── deskpet.log       # 日志文件
└── deskpet.log.1     # 日志轮转备份（最多 5 份）
```

按 `Win + R`，输入 `%APPDATA%\deskpet` 回车即可打开。

## 六、故障排查

### 6.1 宠物启动后一直不播报

1. **检查勿扰时段**：确认当前时间不在 `quiet_hours` 范围内
2. **检查 API Key**：确认 `config.toml` 中 `api_key` 已正确填入
3. **检查日志**：打开 `%APPDATA%\deskpet\deskpet.log`，搜索 `[agent]` 看是否有 `below threshold, skip`（画像为空时打分难以达标，多使用一段时间积累兴趣即可）
4. **手动触发**：双击宠物或托盘菜单"立即播报"，确认能正常弹出气泡

### 6.2 气泡显示"暂时没有值得说的热点"

- 说明采集到的热点都没达到打分阈值
- 新用户画像为空属于正常现象，多反馈几次（喜欢/不感兴趣）让宠物学习你的偏好即可
- 可以适当降低 `announce_threshold`（如设为 `0.4`）

### 6.3 LLM 调用失败

- 检查 `api_base` 是否带 `/v1` 后缀
- 检查 `api_key` 是否正确
- 检查网络是否能访问该 API 端点
- 查看日志中 `[llm] <<< status=` 的返回信息

### 6.4 没有语音播报

- 确认 `config.toml` 中 `tts.enabled = true`
- Edge TTS 需要联网，确认网络畅通
- 检查系统音量和默认音频设备

### 6.5 embedding 不生效

- 确认 `llm.api_key` 已配置
- 日志中出现 `embedding disabled (placeholder fallback)` 表示未配置 API Key 或 `embedding_model` 为空
- 部分服务商（如 DeepSeek、Kimi）不提供 embeddings 接口，需将 `embedding_model` 设为 `""`

## 七、卸载

1. 右键系统托盘图标 → **退出**
2. 通过"设置 → 应用"或控制面板卸载 DeskPet
3. （可选）删除数据目录 `%APPDATA%\deskpet\` 清除所有配置和历史数据
